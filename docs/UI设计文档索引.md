## 二、已确认设计决策（10 项）

| # | 维度 | 决策 |
| --- | ---- | ---- |
| 0 | 产品品牌 | **知练**（KnowPractice）；Slogan：输入学习目标，获得 AI 结构化练测与复盘；场景：校园自学 / 职考 / 企业内训 |
| 1 | 视觉方向 | **Bento 暖橙**高保真 + 水彩横纹纸面；交互为 Duolingo 式单题练测（关卡式） |
| 2 | 文案 | **混合**：主流程温暖；Loading / 对错 / 结算可加漫画梗 |
| 3 | 字体 | 霞鹜文楷屏幕版（全局）+ 得意黑（仅解析/老师笔记区） |
| 4 | MVP 屏数 | **9 屏**（含独立结算 skeleton 态） |
| 5 | 吉祥物 | Loading 使用 `mascots.svg#mascot-think` + 步骤气泡；其余屏待产品定稿 |
| 5a | 灵韵 / 能量条 | **产品 MVP 不做**惩罚式生命值；HTML 原型屏 3–7 可选 `.bt-spirit` 五段条作视觉探索 |
| 5b | 金币 / XP 示意 | **原型已移除**顶栏金币、反馈条「+10 金币」、报告「+20 XP」；产品 gamification 留 uni-app |
| 5c | 屏内布局 | `bt-notch-safe` 避刘海；列表/答题/报告**顶对齐**；仅生成中 `.bt-scroll--center` 垂直居中 |
| 5d | 图标 | 输入框 `.bt-input-icon` 铅笔；答对 `.bt-opt-check` 绿圆章勾 |
| 5e | 底栏 | `bt-tabbar-float` 悬浮胶囊（`phone-screen` 外）；`--bt-screen-paper-bg` 铺底区，无奶油色条带 |
| 5e | 进度条 | `.bt-progress-line` 暖橙双色渐变、8px 圆角、无流光动画；对手 `.bt-progress-line--rival` 蓝色 |
| 6 | 正误色 | 文档漫画色；**实现** `#07c160` / `#fa5151` |
| 7 | 单题计时 | MVP **不做** |
| 8 | 生命值/灵韵 | MVP **不做** |
| 9 | 扩展页 | 02/03 共 11 屏，**中保真** |
| 10 | 502 失败页 | MVP 文档 **不包含**（实现 Toast + 回首页） |
