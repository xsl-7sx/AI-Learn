## 一、设计定位

### 1.1 风格方向

**Bento 暖橙 + 水彩横纹纸面** — 高保真参考稿气质，叠合 Duolingo 单题闯关交互。

| 维度 | 描述 |
|------|------|
| 整体气质 | 温暖、清晰、轻游戏化；拒绝教科书式枯燥 |
| 核心隐喻 | 在横纹笔记本上闯关，AI 帮你翻笔记出题 |
| 情感目标 | 「今天想闯哪一关？」— 低门槛开练 |

### 1.2 参考来源

- 漫画阿衰 — 校园日常 × 搞笑热血
- GoodNotes / Notability 电子手账 — 圆点网格纸 + 手写批注
- Duolingo — 游戏化闯关 + 即时反馈
- 马卡龙色系学习海报 — 低饱和多色卡片 + 箭头引导 + 微涂鸦

## 二、色彩系统

### 2.1 语义色彩 Token

```css
:root {
  /* 纸面 */
  --paper:    #FFFCF5;  /* 暖白纸底 */
  --dot:      #E8E4DC;  /* 圆点网格 */

  /* 文字层级 */
  --ink:      #3D3835;  /* 正文 (9:1) */
  --ink-soft: #6B6560;  /* 辅助文 (5.1:1) */
  --ink-light:#78726E;  /* 脚注/提示 (4.6:1) */

  /* 马卡龙主题色 — 每屏一色 */
  --pink:     #FFD4C4;  --pink-d:   #FF8FAB;  --pink-bg:   #FFF5F2;  /* 粉 */
  --peach:    #FFE0C4;  --peach-d:  #FFB07C;  --peach-bg:   #FFF9F4;  /* 蜜桃 */
  --yellow:   #FFF3CD;  --yellow-d: #FFD166;  --yellow-bg:  #FFFEFA;  /* 黄 */
  --mint:     #D4F0E0;  --mint-d:   #7EC8A4;  --mint-bg:    #F5FCF8;  /* 薄荷 */
  --lavender: #E8DFF5;  --lavender-d:#B8A9D4; --lavender-bg:#FBFAFD;  /* 薰衣草 */
  --sky:      #D4EAF5;  --sky-d:    #89C4E1;  --sky-bg:     #F7FAFC;  /* 天空 */
  --correct:  #C8F0D8;  --correct-d:#4CAF50;                          /* 正确 */
  --wrong:    #FFD4D4;  --wrong-d:  #EF5350;                          /* 错误 */
}
```

### 2.2 页面-颜色映射

| 页面 | 主题色 | 背景渐变 |
|------|--------|----------|
| 首页（输入） | 蜜桃 Peach | `#FFFCF5 → #FFF9F4 → #FFF5F2` |
| 加载中 | 薄荷 Mint | `#FFFCF5 → #F5FCF8 → #F0FAF5` |
| 答题闯关 | 天空 Sky | `#FFFCF5 → #F7FAFC → #F0F7FB` |
| 结算报告 | 薰衣草 Lavender | `#FFFCF5 → #FBFAFD → #F5F0FF` |

### 2.3 对比度合规

| 配对 | 用途 | 对比度 | 达标 |
|------|------|--------|------|
| `--ink` on `--paper` | 正文 | 9.1:1 | AAA |
| `--ink-soft` on `--paper` | 辅助文 | 5.1:1 | AA |
| `--ink-light` on `--paper` | 脚注 | 4.6:1 | AA |
| `white` on `--peach-d` | 按钮 | 3.8:1 | AA (大文本) |

## 六、吉祥物「小萌」

### 6.1 角色设定

| 属性 | 描述 |
|------|------|
| 名字 | 小萌 |
| 形象 | Chibi 风格二次元女孩 |
| 特征 | 大眼、棕色短发、水手服、蝴蝶结、粉色小皮鞋 |
| 性格 | 元气、治愈、偶尔冒失 |
| 道具 | 手持小铅笔 |

### 6.2 5 种表情状态

| 状态 | 触发场景 | 表情特征 |
|------|----------|----------|
| **Normal** | 首页待机 | 微笑 + 正常眼 + 微浮动 |
| **Sweat** | 加载中 | 流汗滴 + 紧张嘴 + 全身颤抖 |
| **Excited** | 答对 | 星眼 + 举手 + 跳跃 + 闪烁星星 |
| **Fallen** | 答错 | X眼 + 摔倒 + 晕眩星 + 抖动 |
| **Graduation** | 结算（高分） | 星眼 + 毕业帽 + 金穗 + 跳跃 |
| **Bandage** | 结算（低分） | 创可贴 + 坚定眼 + 抿嘴 |

### 6.3 技术实现

- 纯 SVG 内联绘制（`<defs>` + `<use>`）
- 各状态复用 `#chibi-normal` 基础图形
- 通过叠加 sweat/badge/cap 等元素切换状态
- 响应式缩放：Hero 手机 ~68×92px，参考网格 ~56×76px

## 九、可访问性规范

### 9.1 已实施的 A11Y 规则

| 规则 | 实施方式 |
|------|----------|
| focus-visible | 蜜桃色 3px 轮廓 + 2px offset |
| reduced-motion | `@media (prefers-reduced-motion)` 全局禁用动画 |
| 最小触摸目标 | 按钮/选项 min-height: 48px |
| 触摸间距 | 选项间距 ≥8px |
| 色彩对比度 | 正文 9:1 / 辅助文 5.1:1 / 脚注 4.6:1 |
| 色彩语义 | 正确=绿+图标 / 错误=红+图标 / 非仅靠颜色传达 |
